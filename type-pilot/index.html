THE SMALL PRINT, SET CLEARLY

Good to know.

What is included in the preview?

Typography inspection, page scanning, four-role pairings, live previews, a searchable library of up to 200 pairings, CSS/JSON exports, backups, and a side-panel workspace. All preview features are free.

Does it download or install fonts?

No. Type Pilot reads the computed CSS font-family declaration. The preview uses fonts available on your device and may show a fallback for website-only fonts. It does not identify text inside images or determine the exact font used for every glyph. Exported CSS preserves the family name; obtain and license font files separately.

Where does my collection live?

In your browser’s local extension storage. No account, analytics, or cloud sync. Export a JSON backup before changing devices or removing the extension. Captured text and source page paths are included in exports; query strings and fragments are stripped.

Can I use it on every page?

It works on regular web pages after you activate it. Browser pages, extension stores, built-in PDF viewers, and embedded frames are not supported. Scans read up to 10,000 elements and retain up to 100 distinct styles. Rescan after dynamic content loads.

Is this related to Palette Pilot?

Yes. Both are made by Stefan Mihajlovic. Palette Pilot helps you build color systems; Type Pilot gives your typography a workspace of its own.
