Type Pilot is a browser typography extension developed by Stefan Mihajlovic. This page describes version 1.0.

What stays on your device

The extension stores your appearance preference, current draft, last captured typography, and saved pairings in your browser’s local extension storage. A captured style can include CSS font properties, a text sample, an element tag, and the source page’s origin and path. Query strings and URL fragments are removed. Samples and paths can still contain personal information.

When a page is read

Type Pilot inspects or scans a page only when you request it. It does not continuously monitor browsing, collect history, use analytics, or send captured content to a server. It does not download remote fonts. Links to this website or GitHub open only when clicked, and those websites have their own data practices.

Permissions

activeTab provides temporary access to a page you activate the extension on. scripting runs the inspector and page scanner. storage saves your local workspace. sidePanel displays the workspace beside your page. No broad host permissions are requested.

Exporting and deleting data

Exports are files saved to your device. JSON backups include captured text and source page paths; review them before sharing. You can delete individual saved pairings in the Library. Removing the extension deletes its local storage, including the last capture and draft. Export a backup first if you want to retain your work. There is no cloud backup or synchronization.
