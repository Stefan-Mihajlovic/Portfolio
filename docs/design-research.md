# Portfolio design investigation — 22 October 2026

## Brief and method

Keep the requested dark space background, the original Spinners stars, top navigation, grainy project-color video loops, centered project images, three selected projects on Home and the full collection on Projects. Remove the generic first-pass presentation.

Inspected 30 usable reference sites in a desktop browser: opening composition, visible typography, links/buttons, hover states, and a scroll sample. Captured hero, hover and scroll screenshots and inspected rendered CSS, video/canvas usage and active animations. Several pages use a custom scroll system, so `scrollY = 0` is not evidence of no movement. These are design observations, not performance benchmarks or proof of how a site was authored.

## What “AI-looking” means here

No font, gradient, rounded corner or animation proves AI authorship. The problem is a collection of unmotivated defaults that could belong to any designer. The first pass had several:

- A role eyebrow, then a generic two-line slogan, then a second paragraph saying essentially the same thing.
- 11–13px category labels, footer links and navigation used to make the layout look “premium.”
- Repeated rounded media cards, circular arrow badges and capsule CTAs.
- The same blur-and-slide reveal applied to unrelated content.
- A made-up `sm*` mark rather than Stefan's existing identity.
- Decorative project dates and location copy that competed with the real work.
- Identical visual cadence from the homepage to every secondary page.

[NN/g's minimalist-design heuristic](https://www.nngroup.com/articles/aesthetic-minimalist-design/) argues for retaining useful information and removing competition around it. That supports deleting duplicated copy, not making the information smaller. [SCALR's pattern critique](https://scalr.sg/blog/20-signs-a-website-was-made-by-ai/) identifies repeated badge, card, typography and motion defaults; it is a design opinion, not an authorship detector. [Emil's animation guidance](https://emilkowal.ski/ui/7-practical-animation-tips) explains rapid feedback, restrained scale changes and origin-aware movement. [His purpose/frequency discussion](https://emilkowal.ski/ui/you-dont-need-animations) is a useful guard against slowing every action down.

The requested grain and moving colors stay: they have a clear reason in this brief. Removing them just because a generic checklist lists gradients would ignore the user's direction.

## Chosen design and implementation rules

Base palette: space `#08090b`, readable white `#f0efed`, secondary text `#b4b4ba`, glass `#ffffff0b`; the project palettes supply all stronger color. No global purple glow.

Type: Switzer, a relatively neutral grotesque with a clear size hierarchy; the existing Medula-based SM identity stays recognizable. Personal name at display scale, role at 26–30px, navigation at 18px, project names at 30–40px, secondary labels at 17–20px. No visible decorative eyebrows.

Desktop composition:

```
SM                         Projects   About   Contact

Stefan Mihajlovic
Designer & developer                         Belgrade, Serbia

[       wide project / grainy film / centered image         ]
OptiFlowz                                    Web design

[     Crimson Music     ]
                           [        Palette Pilot          ]

                                      All projects

Contact                                      actual email
```

Home has no generic slogan, no hero paragraph and no decorative date line. The first project begins in the opening viewport. Selected projects use one wide frame and a pair with different proportions. Projects keeps the complete collection and a simple title. About, Skills and Contact get direct headings instead of more slogans.

Controls: text navigation with a single active treatment; one purposeful hover treatment; larger tap targets. The whole project image is already a link, so remove the repeated round arrow badge.

Motion: the name enters as one typographic composition; project images reveal inside their frames; links and controls react promptly; the persistent stars carry the page transition. Do not send every paragraph through the same blur effect. Respect reduced motion and pause offscreen video.

### Implementation plan and constraints

- Base palette: space `#08090b`, menu `#141519`, type `#f0efed`, secondary `#b4b4ba`, faint lines `#ffffff20`. Project colors belong to the projects, never to the site chrome.
- Switzer remains the main typeface, with the existing Medula SM signature. The hero uses individual letter depth/rotation on entry and a damped pointer wave; no random text scrambling, perpetual marquee, or extra instruction label.
- Homepage: name/role/location → three full-width-within-limit projects → all work → contact. Projects: title → ten vertically stacked projects. Captions stay outside the media.
- Mobile menu: right-hand full-height panel, restrained curved leading edge during entrance, large staggered links, contact at bottom, visible close button. Underlying page is inert while open, focus is trapped, Escape closes, and the same menu persists through navigation.
- Space transition: original Spinners dot radii, brightness, and glints in a persistent perspective field. Camera accelerates then decelerates over 1.35 seconds. Depth persists after navigation; there is no scale reset. Reduced motion uses the static original sky.
