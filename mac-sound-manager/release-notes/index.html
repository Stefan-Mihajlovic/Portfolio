Release notes

What’s new in Mac Sound Manager

0.4.0

November 3, 2026

Output routing and system audio controls

  • Choose a separate output device for each app, or follow the system output
  • Remember device selections across launches and reconnect when devices return
  • Switch the system output, microphone and sound-effects destination, with hardware volume controls where supported
  • Use a cleaner detail panel with separate Output, Equalizer and Balance sections
  • Open System devices from the menu-bar mixer, with the main-window section collapsed by default
  • Use shorter, direct device menus and smooth section expansion
  • Avoid redundant app-list updates and stop periodic audio discovery while the mixer is off or asleep
  • Keep per-app volume up to 200%, mute, ten-band EQ, saved EQ presets, balance and launch-at-login options

A universal development build for Apple Silicon and Intel Macs running macOS 14.2 or later.

Download 0.4.0

Installing this development build

Open the DMG, drag Mac Sound Manager into Applications, then launch it. Allow system audio recording when prompted to enable app processing.

This build is ad-hoc signed, not Developer ID signed or notarized by Apple. If macOS blocks it, review the source before using the app-specific Open Anyway option in System Settings → Privacy & Security.

What to expect

Controls apply to whole apps, not individual browser tabs. Turning processing off restores the app’s original output while keeping its saved settings. The start of playback can be audible before processing begins.

Bluetooth, simultaneous playback through multiple physical devices, long-running clock drift and capture recovery still need broader hardware testing. This remains a development prerelease.

0.3.2

November 2, 2026

The first public development release

  • Separate volume, mute, balance and a 10-band EQ for each app
  • Save, reuse and delete your own EQ presets
  • Set controls for open apps before they start playing
  • Use the menu-bar mixer or the full window, with an optional Dock icon
  • Keep your settings between launches and optionally start at login

Free and open source, with one download for Apple Silicon and Intel Macs running macOS 14.2 or later.

Download 0.3.2

Installing the app

Open the DMG and drag Mac Sound Manager into Applications. Launch it and allow system audio capture when prompted.

This development build is locally signed and is not notarized by Apple. If macOS blocks it, review the source before using Open Anyway in System Settings → Privacy & Security.

Still in development

The start of playback may be audible before processing begins. Bluetooth, output-device changes and capture recovery still need hardware testing. Controls apply to whole apps, rather than individual tabs or windows.
