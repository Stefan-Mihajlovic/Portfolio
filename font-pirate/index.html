Install the preview +
  1. Download and unzip Font Pirate.
  2. Open edge://extensions or chrome://extensions.
  3. Turn on Developer mode, choose Load unpacked, and select the unzipped folder.
Privacy & fonts +

Pairings stay on your device. Google Fonts previews load from Google; your preview text is never sent. Font Pirate reads a page only when you use it. No account, analytics or tracking.

Other website fonts may use a local preview fallback. Captured CSS values stay exact.
